# 🏋️ Academia Vaiana

Aplicação web desenvolvida em Java para gerenciamento de alunos de uma academia. O sistema permite realizar operações completas de CRUD, com cadastro, consulta, atualização e exclusão de registros, utilizando arquitetura MVC e integração com banco de dados.

### Tecnologias
Java • JSP • Servlets • JSTL • MySQL/MariaDB • Apache Tomcat • MVC • DAO

## Funcionalidades
- Cadastro e gerenciamento de alunos
- Consulta por ID e listagem de registros
- Atualização e exclusão de alunos
- Persistência de dados em banco de dados
- Interface web desenvolvida com JSP

> Projeto desenvolvido para fins acadêmicos, com foco na aplicação prática de conceitos de desenvolvimento web, arquitetura MVC e integração entre Java e banco de dados.
